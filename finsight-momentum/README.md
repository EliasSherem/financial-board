# FinSight — paquete para Codex

1. Descomprime este paquete dentro del checkout de FinSight, por ejemplo en docs/briefs/finsight-momentum/.
2. Opcionalmente adjunta también el plan original FinSight_Momentum_Implementation_Plan(1).md como referencia histórica.
3. Abre Codex en el repositorio y pide: “Lee y ejecuta docs/briefs/finsight-momentum/PROMPT_CODEX.md. Integra los assets de este paquete. Completa Momentum, actualización de Google Play Billing, admin de uso/suscripciones por plataforma y recuperación de contraseña. Documenta y prueba el código; no publiques en producción.”
4. Abre PREVIEW.html para revisar las insignias y recursos.

PROMPT_CODEX.md contiene decisiones, criterios de aceptación, seguridad, métricas y pruebas. MOMENTUM_CATALOG.md contiene las 34 insignias y todas las familias de misiones. ASSET_GUIDE.md explica los SVG y su integración.

Este entregable es un prompt y paquete de recursos, no una implementación ya aplicada al repositorio. La compatibilidad actual de SDK, migraciones y compras reales corresponde a la ejecución de Codex sobre el código y entornos reales.
